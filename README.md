# 📊 Bank Loan Data Analysis & Dashboard
## 📌 Project Overview
This project presents an interactive Bank Loan Data Analysis Dashboard built using Microsoft Excel.
The dashboard provides a comprehensive view of loan applications, funded amounts, received amounts, interest rates, debt-to-income ratios, loan performance, and customer characteristics.
The project focuses on transforming loan data into meaningful business insights through interactive dashboards and visualizations.
## 🎯 Project Objectives
- Analyze overall loan application performance
- Monitor funded and received loan amounts
- Analyze good vs. bad loan performance
- Track monthly loan application trends
- Understand loan distribution across states
- Analyze loan purposes
- Examine employment length
- Compare loan terms
- Analyze home ownership patterns
- Monitor average interest rate and DTI
## 🛠️ Tools & Technologies
- Microsoft Excel
- Excel Pivot Tables
- Pivot Charts
- Slicers
- Data Cleaning
- Data Analysis
- Dashboard Design
- KPI Analysis

## 📊 Dashboard Features
### Summary Dashboard
The Summary dashboard provides:
- Total Loan Applications
- Total Funded Amount
- Total Amount Received
- Average Interest Rate
- Average DTI
- Good Loan Analysis
- Bad Loan Analysis
- Loan Status Performance
- Loan Applications by Grade
- Loan Purpose Filtering
### Overview Dashboard
The Overview dashboard includes:
- Loan Applications by Month
- Loan Applications by State
- Loan Applications by Loan Term
- Loan Applications by Employment Length
- Loan Applications by Purpose
- Loan Applications by Home Ownership
### Interactive Filters
Users can filter the dashboard using:
- Loan Grade
- Loan Purpose
- Other available dashboard filters
## 🔑 Key Metrics
The dashboard displays approximately:
- **38.6K** Total Loan Applications

- **$473.1M** Total Amount Received

- **13.82%** Bad Loan Percentage
*Values shown are based on the dashboard dataset used in this project.*
## 📈 Key Analysis Areas
### Loan Performance
Analyzed good and bad loan applications along with funded and received amounts.
### Monthly Trends
Examined the change in loan applications throughout the year.
### Geographic Analysis
Analyzed loan applications across different U.S. states.
### Loan Purpose
Compared applications across purposes such as credit cards, debt consolidation, home improvement, small business, and other categories.
### Customer Profile
Analyzed employment length and home ownership categories.
### Loan Terms
Compared loan applications across different repayment terms.
